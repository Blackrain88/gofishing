# 바다가자

워킹낚시 · 해루질 포인트와 출조 기록을 관리하는 개인용 앱.
기록은 폰 안에 저장되고, 원하면 **내 구글 시트로 동기화**할 수 있습니다.

## 들어 있는 것

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체 (화면 · 로직 · 스타일) |
| `manifest.json` | PWA 설치 정보 |
| `sw.js` | 서비스워커 — 오프라인 캐시 |
| `icon-192.png` / `icon-512.png` / `icon-maskable-512.png` | 앱 아이콘 |
| `Code.gs` | **동기화용 Apps Script** — 구글 시트에 붙여넣는 파일 (GitHub 에 올릴 필요 없음) |

## GitHub Pages 올리기

1. GitHub에서 새 저장소 생성 (예: `badagaja`) — **Public**
2. 이 폴더의 **`Code.gs` 를 뺀 6개 파일을 저장소 최상위에** 업로드 (Add file → Upload files → Commit)
3. 저장소 → **Settings → Pages**
   - Source: `Deploy from a branch`
   - Branch: `main` / `/ (root)` → Save
4. 1~2분 뒤 `https://<아이디>.github.io/badagaja/` 로 접속

> Private 저장소는 Pages가 유료 플랜에서만 됩니다. Public으로 두되, 앱에는 아무 데이터도 들어있지 않으니 (데이터는 각자 폰에만 저장됨) 공개해도 문제없습니다.

## 폰에 설치하기

1. 안드로이드 **Chrome**으로 위 주소 접속
2. 우측 상단 ⋮ → **홈 화면에 추가** (또는 자동으로 뜨는 설치 배너)
3. 홈 화면 아이콘으로 실행하면 주소창 없는 앱처럼 동작

설치 후에는 **비행기 모드에서도 그대로 동작**합니다.

## 앱을 수정한 뒤에

1. `index.html` 의 `APP_VERSION` 과 `sw.js` 의 `VERSION` 숫자를 **함께** 올려 주세요 (`v13` → `v14`).
2. 파일을 올린 뒤 폰에서 앱을 다시 실행하면 반영됩니다.

앱 자체(문서)는 **네트워크 우선**으로 받아오므로, 온라인이라면 실행하는 즉시 최신 버전이 뜹니다.
그래도 옛 화면이 보이면 **설정 → 최신 버전 받기**를 누르세요 — 캐시를 비우고 새로 받습니다
(저장한 포인트·출조 기록은 그대로 남습니다).

지금 폰에서 어떤 버전이 돌고 있는지는 **설정 → 정보**에 표시됩니다.

## 지금까지 되는 것

- 포인트 추가 / 수정 / 삭제 (워킹낚시 · 해루질 타입 구분)
- 시/도 › 구/군 › 장소 3뎁스 콤보 — 입력하면 기존 항목이 걸러지고, 없으면 그대로 새로 등록
- 조과물 프리셋 + 직접 입력 (직접 입력한 항목은 프리셋에 자동 축적)
- 시즌 메모 (월별 · 기간별) — 기간을 고르고 **조과물처럼 프리셋 칩에서 골라** 담습니다. 직접 입력한 항목은 프리셋에 쌓입니다
- **위치 저장 방식을 두 가지 중에서 고릅니다**
  - `현재 위치` — 위도·경도 입력칸 + `현재위치 가져오기`(GPS) + `지도앱으로 열기`. 현장에서 쓰는 방식
  - `지도에서 가져오기` — 지도 링크 입력칸(끝의 ✕로 지움) + `붙여넣기` + `지도앱 실행`. 집에서 등록할 때 쓰는 방식
  - `지도앱 실행`은 **위치가 들어 있으면 그 자리를 열고, 비어 있으면 지도앱만 띄웁니다**
- 지도앱에서 `공유 → 바다가자` → **곧바로 새 포인트 작성 화면이 열리고 `지도에서 가져오기` 모드로 위치가 채워집니다.** 공유된 장소 이름은 제목으로 들어갑니다. 화면 위 배너의 `기존 포인트에 넣기`를 누르면 새로 만드는 대신 기존 포인트에 붙일 수 있습니다
- **지도앱은 시스템이 고릅니다** — 안드로이드 표준 `geo:` 주소를 쓰므로, 설치된 지도앱이 하나면 바로 열리고 여러 개면 선택창이 뜹니다. 앱 목록을 앱이 들고 있지 않습니다
- 좌표가 들어 있는 주소(구글·카카오·네이버 웹)는 자동으로 좌표를 읽어 `geo:`로 엽니다. 단축 주소(`naver.me`, `kko.to`)는 그 주소를 그대로 열어 해당 앱이 받습니다
- `붙여넣기`는 주소뿐 아니라 **좌표만 복사해 온 경우도** 받아 `geo:` 주소로 바꿔줍니다
- 출조 기록 추가 / 수정 / 삭제 — 날짜, 조업 시작·종료 시각, 소요시간 자동 계산, 조과물 수량, 메모, **사진**
- **이미지 첨부** — 포인트는 `포인트 이미지`(지도 캡처에 메모한 것)와 `기타 이미지`로 나눠 담고, 출조 기록에는 사진을 답니다
  - 첨부하면 긴 변 1600px / JPEG 0.8 로 **자동 압축**되고 목록용 썸네일이 따로 만들어집니다
  - 목록·그리드 썸네일은 포인트 이미지 → 없으면 기타 이미지 순으로 잡힙니다
  - 탭하면 전체 화면 뷰어 (좌우 스와이프)
  - 사진이 지워지지 않도록 `navigator.storage.persist()` 로 저장공간 보존을 요청합니다
- **모든 이미지** — 메인 상단의 `모든 이미지 N` 을 누르면 앱에 있는 사진이 최신순으로 한 화면에 모입니다
  - `전체 / 포인트 / 기타 / 출조` 로 종류를 걸러 볼 수 있고, 사진마다 어느 포인트 것인지 이름이 붙습니다
  - 사진을 누르면 그 포인트 상세로 이동합니다
- 메인 리스트 ⇄ 썸네일 그리드, 타입 필터, 통합 검색, 정렬
- 리스트·그리드에 **조과물 표시** — 포인트에 적어둔 것 우선, 없으면 출조 기록에서 집계 (많으면 `+N`)
- 포인트별 누적 조과 집계
- JSON 내보내기 / 가져오기
- **클라우드 동기화 (선택)** — 아래 참조

## 클라우드 동기화 붙이기 (선택)

주소를 넣지 않으면 앱은 **완전히 로컬로만** 동작합니다. 쓰고 싶을 때만 켜면 됩니다.

1. 구글 드라이브에서 **새 스프레드시트** 생성 (이름 아무거나)
2. 시트에서 **확장 프로그램 → Apps Script**
3. `Code.gs` 내용을 통째로 붙여넣고, 맨 위 `TOKEN` 을 아무도 모를 문자열로 변경
4. **배포 → 새 배포 → 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
5. 앱의 **설정 → 클라우드 동기화**에서 `동기화 사용` 스위치를 켠다
6. 나온 웹 앱 주소와 토큰을 넣고 `연결 테스트` → `저장`

스위치를 끄면 아무 데도 보내지 않고 폰에만 저장합니다. **입력해 둔 주소와 토큰은 지워지지 않으므로**, 다시 켜면 그대로 이어서 씁니다. 꺼져 있는 동안 쌓인 변경분은 다시 켠 뒤 한 번에 올라갑니다.

### 무엇이 올라가나

| 대상 | 동작 |
|---|---|
| 포인트 · 출조 기록 | 항상 올라갑니다 |
| **포인트 이미지** | **항상 올라갑니다** (지도 메모라 잃으면 아픈 자료) |
| 기타 이미지 · 출조 사진 | **기본 꺼짐** — 설정에서 켜면 함께 올라갑니다 |

- 기록은 시트에 **읽을 수 있는 형태로** 쌓입니다 (PC에서 그냥 열어봐도 됩니다). 맨 끝 `_json` 열이 복원에 쓰이는 원본입니다
- 사진은 드라이브의 `바다가자/images` 폴더에 파일로 저장되고, 시트에는 파일 id 만 기록됩니다
- 저장할 때마다 4초 뒤 **자동으로 조용히** 올라갑니다. 오프라인이면 건너뛰고 다음 기회에 올립니다
- 앱을 새로 설치했으면 **설정 → 클라우드에서 복원**으로 전부 내려받습니다 (썸네일은 받아서 다시 만듭니다)

### 다시 배포할 때

Apps Script 를 고친 뒤에는 **배포 관리 → 수정 → 버전: 새 버전**으로 올리세요.
`새 배포`를 누르면 주소가 바뀌어서 앱 설정도 다시 넣어야 합니다.

## 알아둘 것

- 데이터는 브라우저의 IndexedDB에 저장됩니다. **크롬 사이트 데이터를 지우면 함께 사라집니다.**
  동기화를 켜지 않을 거라면 설정 → JSON 내보내기로 가끔 백업해 두세요.
- **JSON 내보내기에는 사진이 들어가지 않습니다.** 기록(글)만 들어갑니다. 사진 백업은 클라우드 동기화를 켜야 됩니다.
- 동기화는 **기기 한 대** 기준으로 만들었습니다. 두 대에서 같은 기록을 동시에 고치면 나중에 올린 쪽이 이깁니다.
- 지도 캡처·필기는 앱이 하지 않습니다. 폰에서 캡처 → 원하는 앱으로 메모 → 갤러리 저장 → 앱에서 `포인트 이미지`로 첨부하는 흐름입니다.
- 시크릿 모드에서는 저장이 동작하지 않습니다.
- **길찾기 전용 버튼은 없습니다.** `geo:` 주소로는 "지도에서 보기"까지만 시스템에 넘길 수 있고, 길찾기를 바로 시작하려면 앱별 전용 주소(`nmap://`, `kakaomap://`)가 필요합니다. 그건 지도앱을 몇 개로 못박는 방식이라 뺐습니다. `지도에서 열기` → 열린 지도앱에서 길찾기를 누르는 흐름입니다. 네이버 전용 길찾기 버튼이 따로 필요하면 추가할 수 있습니다.
- 공유 받기(`공유 → 바다가자`)는 **홈 화면에 설치한 뒤에만** 동작합니다. 브라우저 탭으로 열어둔 상태에서는 공유 대상에 뜨지 않습니다.
- `naver.me` · `kko.to` 같은 단축 주소에는 좌표가 들어있지 않아, 시스템 선택창 없이 해당 앱이 바로 받습니다. 4단계에서 Apps Script가 이 주소를 펼쳐 좌표로 바꿔주도록 할 수 있습니다.
- 좌표를 직접 보여주는 지도앱은 구글지도뿐입니다(길게 눌러 핀 → 좌표 글자 탭 → 복사). 네이버·카카오는 `공유 → 바다가자`를 쓰세요.
